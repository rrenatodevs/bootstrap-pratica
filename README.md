# Saúde Mental e Hábitos Saudáveis
 
Site responsivo de 5 páginas sobre saúde mental e hábitos saudáveis (exercícios, sono, alimentação e qualidade de vida), desenvolvido com **HTML5, CSS3 e Bootstrap 5**.
 
Projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas (UNICID).
 
## Acesse o projeto
 
- **Site publicado (GitHub Pages):** https://rrenatodevs.github.io/bootstrap-pratica/
- **Repositório:** https://github.com/rrenatodevs/bootstrap-pratica
## Páginas
 
| Página | Arquivo | Conteúdo |
|---|---|---|
| Início | `index.html` | Carousel de destaques, resumo do site e chamadas para as demais seções |
| Sobre | `sobre.html` | Contextualização do tema com o sistema de grid do Bootstrap |
| Galeria | `galeria.html` | Cards responsivos com modais de informações extras |
| Dados | `dados.html` | Tabela estilizada e perguntas frequentes em accordion |
| Contato | `contato.html` | Formulário com classes de formulário do Bootstrap |
 
## Recursos utilizados
 
- Navbar responsiva com menu hambúrguer, igual em todas as páginas
- Sistema de grid (`container`, `row`, `col-*`) com pontos de quebra para celular, tablet e desktop
- Componentes do Bootstrap: Carousel, Cards, Modal, Table, Accordion e Form
- HTML semântico (`header`, `main`, `section`, `footer`)
- `css/style.css` próprio, apenas com ajustes pontuais (por exemplo, o sublinhado do link da página atual)
- Caminhos relativos para imagens, estilos e links entre páginas

## Como executar localmente
 
1. Clone o repositório:
```
   git clone https://github.com/rrenatodevs/bootstrap-pratica.git
```
2. Abra a pasta no VS Code.
3. Abra o `index.html` no navegador ou use a extensão Live Server.
Não é preciso instalar nada, pois o Bootstrap é carregado por CDN.
